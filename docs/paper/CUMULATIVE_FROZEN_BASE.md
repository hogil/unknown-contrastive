## 결정 (260616 02:05) + 다음 진짜 레버
═══════════════════════════════════════════════════════════════════
- cum10_lg 10ep 완주로 **완전 증거** 확보: ep10 cap 0.655 / recov 0.178 (ep1 대비 붕괴). 나머지 config(nv/sn/ls) 10ep 는 동일 붕괴 9시간 반복이라 **중단** (필요시 재실행 가능).
- **결론: epoch 은 개선 레버 아님. ep1(light adaptation) 이 최적.** 현 best = ep1 레시피 (q4k recov 0.501, local-grid 0.15 파편비 1.69) 유지.
- **다음 진짜 레버 후보** (epoch 아닌 것 — 사용자 복귀 시 결정):
  1. **backbone freeze (lr_bb=0) + head-only 학습**: 붕괴 원인이 backbone 의 source 과적합이면, head 만 학습 시 더 많은 epoch 도 안전할 수 있음 (직접 검증 대상).
  2. **augmentation 변경**: 현 aug 가 cross-dataset gap 못 메우는지.
  3. **절대 천장 인정**: lattice-neighbor cosine 0.996 (같은 모양 다른 위치 = 거의 동일) = cross-dataset multi-label 본질 한계. ep1 레시피가 실용적 답.
