# Component Contributions over Frozen DINOv3 — Paper Table (mixed29)

라벨 없는 wafer 풀에서 처음 보는 결함을 그룹으로 발견. 학습-평가 무겹침, 무라벨(SSL), **백본 = DINOv3 frozen 이 진짜 baseline (학습 0)**.
클러스터러 = FINCH p1 (parameter-free, 다이얼 0). 데이터셋 = **mixed29** (WM-811K 단일 → MixedWM38 혼합 29 combo, multi-label 중첩 = 유일 난제).

지표: **P1 capture | recov | P2 noise% | P3 Comp | P4 Hom | ARI | Sil | k(전체클러스터/클래스수/noise클러스터) | 파편비(전체÷클래스, 1.0=이상)**.
★ 주 판정축 = **capture + 파편비** (recov 후순위). 파편비 = 과파편 정도, 1.0 = 클래스당 1클러스터(이상).

## ★ 최종 종합 (값 스윕 전부 완료) — 방법별 축 챔피언
═══════════════════════════════════════════════════════════════════

| 방법 (최적값) | P1 cap | recov | P4 Hom | ARI | 파편비 | 어느 축 챔피언 |
|---|---|---|---|---|---|---|
| frozen base | 0.931 | 0.376 | 0.528 | 0.192 | 2.03 | (기준) |
| **local-grid 0.15** | 0.966 | 0.389 | 0.557 | 0.198 | **1.69** | ★ **파편비** (위치 묶음) |
| NeCo 0.2 | **1.000** | 0.481 | **0.633** | 0.204 | 2.59 | ★ **capture** + Hom |
| MoCo (m0.99) | 0.966 | 0.477 | 0.616 | 0.222 | 2.07 | 균형 |
| NV 0.90 | 0.966 | **0.523** | 0.660 | **0.242** | 2.48 | ★ **recov/capture 동시** |

**값 스윕 결론:**
- **파편비+capture 우선 (사용자 1순위) → local-grid 0.15** (파편비 1.69, cap 0.966). NeCo/MoCo/NV 모두 파편비 ≥2.07 로 못 따라옴.
- local/NeCo 는 **둘 다 patch/위치 계열 = 하나만 선택**. 파편비면 local, capture 만점이면 NeCo.
- NeCo 파편비 floor ~2.24 (값 무관), local 은 0.15 가 sweet spot (0.20+ 는 capture 붕괴).
- NV 는 recov+capture 동시 best 지만 **파편비 미개선** → 파편비 목적엔 부적합, recov 목적엔 최선.

## 핵심 메시지 (paper narrative)
═══════════════════════════════════════════════════════════════════

1. **진짜 baseline = frozen DINOv3** (학습 0, cap 0.931 / 파편비 2.03). q4k(SimCLR+queue)는 이미 queue(=MoCo 메커니즘)가 들어간 부품 조합이라 baseline 아님.
2. **위치·patch 계열(local-grid/NeCo/MoCo)이 frozen 대비 전부 향상** — 반도체 결함의 **위치 특성**을 포착해 capture·Hom·파편비 개선.
3. **두 축의 trade-off**:
   - **capture + 파편비 우선** → local-grid 0.15 (파편비 1.69, cap 0.966) / NeCo (cap 1.0)
   - **recov + ARI 우선** → KoLeo / 조합 (파편비 대가)
4. **미해결**: cap 1.0 ∧ 파편비→1.0 동시 달성. 진행 중 sweep (local-grid 0.20~0.30, NeCo 0.5/1.0, MoCo momentum) 으로 탐색 중.

(진행 중 vn_* sweep 결과는 완료되는 대로 Table 1 에 행 추가)
